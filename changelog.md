# Changelog

## 1.0.0
- Initial official release of UnigramAccess with complete modular architecture rewrite.
- Added dedicated accessibility keyboard shortcuts for navigation, messages, media, calls, and search.
- Added advanced voice message controls: audio/text recording indicators, playback toggling, speed switching, slider focus, and speech-to-text recognition.
- Added chat message monitoring (`ALT+L`) and chat activity tracking (`ALT+T`).
- Added global call management (`ALT+Y` to answer, `ALT+N` to decline/hang up) and in-call mic/camera toggles.
- Enhanced speech verbosity, message formatting, smart file/media details, and progress bar suppression.
- Added dedicated configuration panel in NVDA settings with diagnostic logging management.
