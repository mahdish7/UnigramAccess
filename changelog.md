# Changelog

## 1.0.0
- Initial official release of UnigramAccess with complete modular architecture.
- Comprehensive keyboard accessibility and fast navigation across chats, folders, and message lists.
- Enhanced message interaction, quick actions, attachment saving, and rich formatting for replied messages.
- Advanced voice and media message management: recording indicators, playback and speed controls, and speech-to-text recognition.
- Real-time chat activity tracking and automatic incoming message monitoring.
- Seamless call management and conference audio/video controls.
- Reduced screen reader verbosity, progress bar cleanup, and smart file/link preview details.
- Dedicated configuration panel in NVDA settings with diagnostic logging management.
- Complete Persian (fa) localization and bilingual documentation.
- And various other accessibility enhancements and performance improvements.
